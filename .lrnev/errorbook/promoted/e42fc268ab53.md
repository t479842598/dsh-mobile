# e42fc268ab53

## 症状

调用 Typert 端点 POST /api/commands/execute（如 /permission 切权限）时返回 arguments-invalid … missing \"images\"。

## 根因

harness 新版 commands/execute 参数 descriptor 将 images 列为必填字段，未传直接报错（上游 Mobile Gateway 曾因此权限切换失败，补 images: [] 后修复）。

## 修复动作

调用 commands/execute 时显式携带 images: []（空数组也必须传）；来源：上游 Clarklevis1995/dsh-mobile commit 6f55f3c 踩坑记录，其 Mobile Gateway 修复后 53 个 dispatch 用例通过。

## 验证证据

2026-08-29 在本机 harness 0.1.1-rc.2（127.0.0.1:3080）实测：POST /api/commands/execute（envelope {type:client-request, method:commands/execute, payload:{args:{agentId:<sessionId>, line:"/x"}}}）不带 images 返回 internal "missing \"images\""；带 images:[] 返回 {"ok":true}。同时确认 Typert payload 必须形如 {"args":{...}}、method 必须匹配端点路径（commands/execute），agentId 即 sessionId。
